# Mess Pass

A simple, offline-first web app for managing your daily mess QR coupons.

**Everything stays 100% local on your device.** No servers, no accounts, no tracking, and no data ever leaves your browser. Once loaded, it works completely offline.

## Features

- **Local and Offline**
- **Minimal Storage Footprint**
- **Offline Multi-Page PDF Accepted**
- **Time-of-Day Smart Highlighting & Auto-Selection:**
  - **Breakfast:** 7:00 – 10:00 AM
  - **Lunch:** 12:00 – 2:30 PM
  - **Snacks:** 4:30 – 5:30 PM
  - **Dinner:** 7:00 – 9:30 PM
- **Camera QR Scanner**
- **Device Transfer & Backup**

## Getting Started

```bash
npm install
npm run dev
```
